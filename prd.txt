   1. Executive Overview & Mission

Solar filaments are dense, high-temperature plasma structures suspended by magnetic field lines above the
solar photosphere. Accurate segmentation of filaments in ground-based H-Alpha observations is critical for
space weather forecasting, early prediction of Coronal Mass Ejections (CMEs), and solar flare warning systems.
This Product Requirement Document (PRD) defines the complete technical, architectural, and algorithmic
specifications for building an automated, state-of-the-art instance segmentation system optimized for the
MAGFiLO benchmark dataset.

   6. Data Preprocessing & Model Strategy

    Preprocessing Pipeline Protocol:
     1. Solar Disk Masking: Automated Hough circle detection extracts the solar disk, assigning off-disk deep space
     background to null.
     2. Contrast Limited Adaptive Histogram Equalization (CLAHE): Applied with a clip limit of 2.0 and tile grid size of 8×8
     to enhance low-contrast barb filaments.
     3. Composite Loss Formulation: To force model attention onto thin features, training utilizes a dual Tversky and Focal
     Loss formulation:

              Ltotal =  · LFocal +  · LTversky | Tversky(P, G) = |P G| / (|P G| + 0.3|P \ G| + 0.7|G \ P|)

The asymmetry parameters ( = 0.3,  = 0.7) specifically penalize False Negatives (missing barb extensions) at
more than double the weight of False Positives, ensuring fine thread recovery during gradient optimization.

9. Official Panoptic Quality Metric Formulation

Metric Engine Logic: Panoptic Quality (PQ) evaluates matching segment pairs (y, ) where IoU(y, ) > 0.5:
                                    PQ(Y, ) = (y, )  TP IoU(y, ) / [ |TP| + 0.5|FP| + 0.5|FN| ]

 Where IoU(y, ) = (y  ) / (y   y  ). Any predicted segment with IoU  0.5 is categorized as a False

Positive, penalizing the denominator.

   13. Agent Implementation Directives

Autonomous engineering agents executing this specification must strictly observe the following constraints:
· Memory Management: Pre-tile 2048×2048 high-resolution H-Alpha solar images into overlapping 1024×1024
patches during training, recombining instance masks via Test-Time Augmentation (TTA) during inference.
· No Hard-coded Suffixes: Ensure instance index generators uniquely tag every predicted mask per image key.
· Format Verification: Validate that exported RLE strings do not contain quotation marks and map cleanly to
binary masks matching the source dimensions.
