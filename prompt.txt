1. EXECUTIVE GOAL & CONTEXT
--------------------------------------------------------------------------------
- Objective: Instance-level segmentation of solar filaments from high-resolution (2048x2048) 
  8-bit grayscale H-Alpha solar imagery.
- Primary Evaluation Metric: Panoptic Quality (PQ) @ IoU threshold 0.5.
  PQ = Σ IoU(y, ŷ) / (|TP| + 0.5|FP| + 0.5|FN|)
- Key Technical Challenges:
  1. Preserving thin, thread-like filament "barbs".
  2. Resolving multi-annotator ground-truth JSON entries (`<annotator_id>-<file_name>`).
  3. Avoiding 1-to-many fragmentation penalties (1:n links).
  4. Preventing many-to-one over-merging penalties (m:1 links).
  5. Suppressing background solar noise.

--------------------------------------------------------------------------------
2. DATASET LAYOUT & ANNOTATION PARSING RULES
--------------------------------------------------------------------------------
Data Path Hierarchy:
  MAGFiLO_1.0_Kaggle_2026/
  ├── train/
  │   ├── train_images/                 # 2048x2048 8-bit grayscale JPEGs (YYYYMMDDHHMMSSII.jpeg)
  │   └── MAGFiLO_1.0_Annotations_kaggle2026_train.json # COCO JSON
  └── test/
      └── test_images/                  # Test set H-Alpha JPEGs

COCO Parsing Directives:
1. `images[].id` is formatted as `<annotator_id>-<file_name_without_ext>` (e.g., `010401-20160920230134Lh`).
2. Multiple entries in `images` may reference the same image file with different annotator prefixes. 
   Treat each `images[].id` as a distinct independent sample in the PyTorch Dataset.
3. `annotations[].segmentation` contains polygon coordinates `[[x0, y0, ..., xn, yn]]`. 
   Convert to binary masks using `pycocotools.mask.frPyObjects(poly, 2048, 2048)` and `decode()`.
4. All categories (1: Left, 2: Right, 3: Unidentifiable, 4: Ambiguous) map to class ID 1.
5. 3-Channel Adapter: Grayscale input images (1x2048x2048) must be expanded to 3 channels (3x2048x2048) for backbone compatibility.
